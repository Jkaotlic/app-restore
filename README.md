# Вернуть приложения

Настольная программа для macOS и Windows. Она возвращает на iPhone приложения, которые вы раньше скачивали со своего Apple ID: находит их в покупках, скачивает официальные копии с серверов Apple и ставит на телефон по кабелю. Как в iMazing, только проще.

## Как это выглядит

1. **Apple ID.** Выбираете аккаунт, в который уже входили, или добавляете новый. Сохранённые сессии переключаются без повторного ввода пароля.
2. **iPhone.** Подключаете телефон кабелем. Программа видит, что на нём уже стоит, и с какого Apple ID он работает.
3. **Выбор.** Каталог приложений, которые сложно найти в магазине, и все ваши покупки с поиском. У каждой строки две версии: «на iPhone» и «доступно». Уже установленное по умолчанию не отмечено.
4. **Готово.** Скачивание и установка с прогрессом, кнопка «Повторить» у каждой строки.

Ещё в программе есть:

- **«Все копии».** Любую скачанную ранее копию `.ipa` можно поставить на любой подключённый телефон, в том числе без входа. Можно выбрать и свой файл `.ipa`.
- **«Мои приложения».** Копии лежат локально, отдельная папка на каждый Apple ID. Их можно поставить повторно и тогда, когда магазин недоступен.
- **Поиск по всему сразу**: по каталогу, покупкам и телефону, в том числе по прежним названиям. Ищете «Сбер» и видите все выпуски, включая вышедшие под другими именами. Фильтры: банки, соцсети и почта, транспорт, «на iPhone», «есть новее».
- **Старый телефон как источник.** Подключите старый iPhone: программа покажет, что на нём стоит из пропавшего в магазине, и скачает копии с Apple, чтобы поставить на новый.
- **Добавление по ссылке App Store**, если нужного приложения нет в каталоге, и кнопка «Сообщить в каталог».
- **Честные подсказки.** Например, «только для iPad» или «на этом iPhone другой Apple ID: при первом запуске телефон попросит войти в Apple ID покупателя».

## Что программа не делает

- Не покупает приложения и не берёт новые лицензии. Работает только с тем, что уже есть на вашем аккаунте.
- Не обходит защиту Apple. Приложение запускается под Apple ID покупателя.
- Не хранит пароль. Пароль нужен только в момент входа, сессии лежат в Связке ключей macOS или в Диспетчере учётных данных Windows.

## Установка

Готовые сборки лежат в [Releases](../../releases).

- **macOS 12+** (Apple Silicon и Intel): откройте `.dmg` и перетащите программу в «Программы». Программа не подписана сертификатом Apple, поэтому macOS при первом запуске скажет, что её «не удаётся проверить» или что она «повреждена». Проще всего один раз выполнить в «Терминале»:

  ```bash
  sudo xattr -dr com.apple.quarantine "/Applications/Вернуть приложения.app"
  ```

  Терминал спросит пароль от Mac (символы при вводе не видны). Другие способы: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», или правой кнопкой по программе → «Открыть» (macOS 14 и старше).
- **Windows 10/11 x64**: в работе, ждём исправления в ipatool ([#637](https://github.com/majd/ipatool/issues/637)). Для связи с iPhone понадобится приложение «Apple Devices» из Microsoft Store.

Нужен кабель USB. При первом подключении на iPhone нажмите «Доверять».

> Программа неофициальная. Используйте Apple ID, к которому у вас есть доверенный телефон: Apple может временно ограничить вход.

## Сборка из исходников

Понадобятся Rust 1.88+, Node 20+ и Xcode Command Line Tools (на macOS).

```bash
npm ci
scripts/fetch-ipatool.sh   # закреплённая версия ipatool, проверка sha256
npm run tauri build        # .dmg в src-tauri/target/release/bundle
```

Тесты:

```bash
(cd src-tauri && cargo test)
npm test
python3 -m unittest scripts/test_catalog_check.py
```

## Как устроено

- **Tauri 2.** Логика на Rust (`src-tauri/src`), интерфейс на TypeScript без фреймворков (`src`).
- **[ipatool](https://github.com/majd/ipatool) (MIT)** — вложенный бинарник, через него идёт общение с App Store. Протокол Apple программа сама не реализует. Когда Apple что-то меняет, достаточно обновить ipatool.
- **[idevice](https://github.com/jkcoxson/idevice).** С его помощью программа устанавливает на iPhone через usbmux (AFC и installation_proxy) и читает список установленного.
- **Каталог** (`catalog/`). Список приложений с id App Store. Программа подтягивает свежую версию при запуске, а еженедельный GitHub Actions проверяет записи, ищет новые выпуски под другими именами в новостях и у тех же разработчиков и присылает pull request или issue с кандидатами. Формат описан в [`catalog/schema.md`](catalog/schema.md).
